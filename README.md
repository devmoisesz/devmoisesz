## 🚀 Projetos

### 🔗 Vitrine Web

Uma plataforma completa de catálogo digital para lojas de moda, desenvolvida para simplificar a apresentação de produtos, o gerenciamento de estoque e a geração automatizada de pedidos enviados diretamente pelo WhatsApp, sem taxas de transação de APIs de pagamento.

**Tecnologias utilizadas:**

![Node.js](https://img.shields.io/badge/Node.js-339933?style=for-the-badge\&logo=nodedotjs\&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge\&logo=typescript\&logoColor=white)
![NestJS](https://img.shields.io/badge/NestJS-E0234E?style=for-the-badge\&logo=nestjs\&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-316192?style=for-the-badge\&logo=postgresql\&logoColor=white)
![Prisma](https://img.shields.io/badge/Prisma-2D3748?style=for-the-badge\&logo=prisma\&logoColor=white)
![Cloudinary](https://img.shields.io/badge/Cloudinary-3448C5?style=for-the-badge\&logo=cloudinary\&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=for-the-badge\&logo=docker\&logoColor=white)
![GitHub Actions](https://img.shields.io/badge/GitHubActions-181717?style=for-the-badge\&logo=githubactions\&logoColor=white)
![Swagger](https://img.shields.io/badge/Swagger-85EA2D?style=for-the-badge\&logo=swagger\&logoColor=black)
![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge\&logo=nextdotjs\&logoColor=white)

**Principais funcionalidades:**

* Autenticação de usuários e controle de acesso
* Catálogo digital interativo com filtros por categoria e busca
* Carrinho de compras com seleção de variações, tamanhos e quantidades dos produtos
* Geração automatizada de pedidos enviados diretamente pelo WhatsApp
* Painel administrativo para gerenciamento de produtos, imagens (Cloudinary) e estoque
* Gerenciamento de banco de dados relacional com PostgreSQL e Prisma ORM
* Validação de esquemas com segurança de tipos utilizando Zod
* Documentação interativa da API desenvolvida com Swagger
* Front-end responsivo desenvolvido com Next.js

**Link do site:** 🔗 https://vitrineweb-app.vercel.app/

**Link do repositório Back-End:** 🔗 https://github.com/devmoisesz/vitrine-web-api

**Link do repositório Front-End:** 🔗 https://github.com/devmoisesz/vitrine-web

### 🔗 Link Shortener

Aplicação full-stack para encurtamento e gerenciamento de URLs, desenvolvida para praticar autenticação, design de APIs, paginação e integração com MongoDB.

**Tecnologias utilizadas:**

![Node.js](https://img.shields.io/badge/Node.js-339933?style=for-the-badge\&logo=nodedotjs\&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge\&logo=typescript\&logoColor=white)
![Express](https://img.shields.io/badge/Express-000000?style=for-the-badge\&logo=express\&logoColor=white)
![MongoDB](https://img.shields.io/badge/MongoDB-47A248?style=for-the-badge\&logo=mongodb\&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=for-the-badge\&logo=react\&logoColor=61DAFB)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge\&logo=vite\&logoColor=white)
![Git](https://img.shields.io/badge/Git-F05032?style=for-the-badge\&logo=git\&logoColor=white)
![GitHub Actions](https://img.shields.io/badge/GitHubActions-181717?style=for-the-badge\&logo=githubactions\&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=for-the-badge\&logo=docker\&logoColor=white)
![Swagger](https://img.shields.io/badge/Swagger-85EA2D?style=for-the-badge\&logo=swagger\&logoColor=black)

**Principais funcionalidades:**

* Autenticação de usuários com JWT
* Criação de URLs curtas com códigos exclusivos
* Redirecionamento para as URLs originais
* Listagem de URLs do usuário com paginação
* Exclusão de URLs com validação de propriedade
* Integração com MongoDB utilizando Mongoose
* Front-end responsivo desenvolvido com React

**Link do repositório:** 🔗 https://github.com/devmoisesz/link-shortener
